# Scayla · מזמינים את מנועי ה-AI לזחול ולצטט
#
# הערה חשובה לתחזוקה: כלל Disallow חייב לחזור בכל בלוק User-agent.
# בוט קורא רק את הבלוק הספציפי ביותר שתואם לו · אם הוא מוגדר בנפרד,
# הוא מתעלם לחלוטין מהבלוק של "User-agent: *". לכן /api/ חסום בכל בלוק.
#
# מה חסום ולמה:
#   /api/  · נקודות הקצה שמקבלות ומחזירות פרטים אישיים (טפסי לידים, בדיקת
#            נראות, סטטוס סריקה). חסימה כאן מונעת זליגת נתונים לאינדקס.
# מה לא חסום בכוונה:
#   /quizz ו-/scan הם טפסים · הם לא מכילים נתוני גולשים, רק אוספים אותם.
#   הם מסומנים noindex ומוחרגים ממפת האתר. אסור לחסום אותם כאן: בוט שחסום
#   מלסרוק אותם לא יראה את תגית ה-noindex, והכתובת עלולה להיכנס לאינדקס
#   בלי תוכן. חסימה = פחות שליטה, לא יותר.
